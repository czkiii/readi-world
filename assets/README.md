# Assets

This clean runtime contains no inherited production asset. Its first approved
new production family is the I4 standard harvestable pine package under
`environment/pine/`: standing tree, matching stump, and contact shadow.

Each future asset family requires an approved specification, manifest entry,
registry metadata, validation, and real-device acceptance test before it can
be activated.

Files placed in this folder are inert until `data/assets-manifest.json`
registers them. Gameplay and stage code request controlled semantic roles and
tags; exact asset ids are reserved for authored landmarks and explicit
animation states.

The I4 pine files are lossless WebP exports copied from the verified
`art-source/30_normalized/` family. Editable PSD masters and normalized PNGs
remain outside the shipped runtime.
