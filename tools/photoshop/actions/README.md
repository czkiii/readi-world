# Readi World Photoshop Actions

Ez a mappa a helyi Photoshop 2020 Action-készlet visszaállítható `.atn`
biztonsági mentésének helye.

## Kanonikus helyi beállítás

- Action: `ReadiWorldScript`
- Shortcut: `Shift+Ctrl+F12` (`Ctrl+Shift+F12` ugyanaz)
- Dispatcher:
  `C:\Users\bobaa\Documents\ReadiWorldGameDeskopt\tools\photoshop\ReadiWorldScript.jsx`
- Workspace: `Readi World`
- Használat: maximalizált Photoshop-ablak
- Beállítás igazolva: 2026-08-02

## Egyszeri Action-backup

1. Az Actions panelen jelöld ki azt az Action setet, amely a
   `ReadiWorldScript` Actiont tartalmazza.
2. Panelmenü → `Save Actions...`.
3. Mentsd ide `Readi-World-PS2020.atn` néven.

Photoshop-reset vagy újratelepítés után a panelmenü `Load Actions...` parancsával
ugyanez a fájl visszatölthető. Az `.atn` csak kényelmi backup; a script és a projekt
szabályainak igazságforrása továbbra is a repository.
